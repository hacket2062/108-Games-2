## 現況

- React／TypeScript／Vite；國語探索戰鬥、英文戰機、數學塔防、自然料理四個遊戲。
- 有年級／學期、武器寶石、精靈夥伴、章節選關、錯題本、本機多學生與 Firebase Google 登入／個人雲端存檔。
- 已有四科插畫入口、下一關推薦、同關重試；正在增加戰前操作教學、暫停時重看說明、自由練習選關及真實結算回饋。
- 目前完整題庫／適應性／素養題／1～4 人共鬥／17 份 Boss 劇本仍是後續目標，不可假設已完成。
- 正式真人對戰暫停，舊規則與權威後端尚未驗收。前端功能不會自動修好後端權限。
- 玩家資產、UID、進度必須保留；自由練習不應解鎖冒險星星或領取冒險首通寶箱。

## 請交付

1. 排序 6 項最能改善孩子第一次遊玩、理解規則、遇到困難後願意再試的功能。
2. 每項提供：孩子遇到的具體問題、功能行為、三至四年級與五至六年級差異、手機／鍵盤操作、完成判準、資料與安全風險。
3. 前 2 項寫成工程師可以直接實作的 user stories 與 Given/When/Then 驗收案例，包含失敗、退出、暫停與重試。
4. 對「戰前教學」「自由練習不改冒險通關」「結算後去錯題本」提出具體挑戰與修正建議。
5. 建議下一批可先完成的一個四科共用垂直流程，以及兩個最值得保留給後續的較大型玩法。
6. 提供可由孩子試玩的觀察問題；不要以開發者或 AI 的喜好宣稱孩子一定喜歡。

## 限制

- 不使用假進度、假在線人數、假真人或未作答 100% 正確率。
- 不以每日斷簽懲罰、隨機抽獎付費、羞辱答錯或逼迫延長遊玩時間來增加黏著。
- 不傳送學生個資給外部模型，不讓即時 LLM 單獨決定正誤、學力或排名。
- 區分「這次答對」與「已獨立掌握」；少量作答不能推斷完整學力。
- 需求應可分批落地，不直接要求整包砍掉重寫。
